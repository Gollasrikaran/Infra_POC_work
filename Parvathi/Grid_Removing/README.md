\# Single Image Extraction



\## Purpose

This module extracts individual images from engineering drawing PDF files for further processing.



\## Team Contribution

Developed the module to:

\- Extract images from PDF pages.

\- Save each image individually.

\- Support image preprocessing for subsequent modules.



\## Completed

\- Single image extraction from PDF.

\- Image saving functionality.



\## Currently In Progress

\- Improving extraction quality.

\- Optimizing extraction speed.



\## Dependencies

\- Python 3.x

\- PyMuPDF (fitz)

\- Pillow (if used)



Install dependencies:

pip install pymupdf pillow



\## Setup Instructions

1\. Install the required libraries.

2\. Place the input PDF in the project folder.

3\. Update the PDF path if needed.

4\. Run:

&#x20;  python single\_image\_extraction.py



\## Feasibility Report

The module successfully extracts individual images from engineering drawing PDFs and prepares them for downstream processing.
