\# 19-Series Extraction with Scale Detection



\## Purpose

This module extracts horizontal and vertical scale information from 19-series cross-section engineering drawing PDFs.



\## Team Contribution

Developed the module to:

\- Identify 19-series drawings.

\- Filter Cross Section pages.

\- Extract Horizontal and Vertical Scale.

\- Generate a simplified scale report.



\## Completed

\- 19-Series identification

\- Cross Section filtering

\- Horizontal scale extraction

\- Vertical scale extraction

\- Scale report generation



\## Currently In Progress

\- Improving extraction accuracy for different drawing formats.

\- Optimizing processing speed.



\## Dependencies

\- Python 3.x

\- PyMuPDF (fitz)

\- re (Regular Expressions)

\- os



Install dependency:

pip install pymupdf



\## Setup Instructions

1\. Install Python.

2\. Install PyMuPDF:

&#x20;  pip install pymupdf

3\. Place the PDF in the project folder.

4\. Update the PDF path if required.

5\. Run:

&#x20;  python series\_extraction.py



\## Feasibility Report

The module successfully extracts scale information from 19-series cross-section drawings. It is currently being enhanced to support additional drawing formats.
